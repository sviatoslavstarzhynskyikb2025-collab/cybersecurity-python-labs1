# Лабораторна робота №2. Управління користувачами та аналіз логів

## Призначення
Мета лабораторної роботи — розробка об'єктно-орієнтованої структури для керування користувачами, ролями та системою аудиту безпеки (Task 1), а також створення утиліти для аналізу файлів активності та виявлення аномалій (Task 2).

## Структура проєкту
- `task1.py` — класи для керування користувачами (`User`, `Admin`), сесіями (`Session`), журналом аудиту (`AuditLog`) та обліковими записами (`UserAccount`).
- `task2.py` — клас `UserActivityAnalyzer` для зчитування CSV-логів, пошуку позаурочної активності та збереження результатів у JSON-звіт.
- `main.py` — головний файл для запуску програми через консоль (режими `demo` та `analyze`).
